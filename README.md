
# Streamlit Dashboard for Smart Bus Scheduling System

## How to run (local)

1. Create a Python environment (recommended):
   ```bash
   python -m venv venv
   source venv/bin/activate   # on Windows: venv\Scripts\activate
   pip install -r requirements.txt
   ```

2. Ensure `outputs/` contains the following files (generated by backend scripts):
   - bus_allocation_plan.csv
   - predicted_daily_boardings_example_wed.csv
   - sensitivity_trips_per_bus.csv

   If you don't have these, run the backend scripts in the original project to generate them, or copy sample files into `outputs/`.

3. Run the dashboard:
   ```bash
   streamlit run working_dashboard.py
   ```

Open http://localhost:8501 in your browser.
